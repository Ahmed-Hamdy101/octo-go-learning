# Chapter 4: Input and parsing

This chapter covers how to read input from the user and convert values.

## Key ideas

- use `bufio.NewReader` to read input
- use `fmt.Scanln` for simple input
- use `strconv.ParseFloat` to convert strings into numbers
- use `strings.TrimSpace` to clean input before parsing

## Example files

- `bufio_os.go` : reads a string from the console
- `gettingInput.go` : uses `fmt.Scanln` to collect input
- `useParseConvReader.go` : parses a numeric string into a float

## What to learn

- how to collect input from users
- how to convert text to numbers
- how to handle simple parsing errors
