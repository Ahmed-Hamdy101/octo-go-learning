# Chapter 3: Formatting and strings

This chapter focuses on string output and formatting in Go.

## Key ideas

- use `fmt.Printf` for formatted output
- use `%v` for values and `%T` for data types
- use `%f` or `%.2f` to format floating-point numbers
- learn how `fmt.Println` returns a value and an error

## Example files

- `printFormat.go` : demonstrates placeholders and data types
- `strLength.go` : shows how to print string length and handle errors

## What to learn

- how to print values clearly
- how to inspect variable types
- how to format output for better readability
