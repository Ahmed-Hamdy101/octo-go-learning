# Chapter 6: Date and time

This chapter introduces time handling in Go.

## Key ideas

- use the `time` package for dates and times
- create specific dates with `time.Date`
- use `time.Now()` to get the current time
- add or compare dates with helper methods

## Example file

- `date_calculation.go` : shows how to create a date and calculate tomorrow

## What to learn

- how to work with time values
- how to format and inspect dates
- how to perform simple date calculations
