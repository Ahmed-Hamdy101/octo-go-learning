# Chapter 7: Pointers

This chapter introduces pointers, which are used to reference memory locations.

## Key ideas

- a pointer stores the address of a value
- use `&` to get the address of a variable
- use `*` to access the value pointed to
- pointers are useful when passing values efficiently or modifying them indirectly

## Example file

- `pointer.go` : demonstrates nil pointers, assignment, and pointer usage

## What to learn

- the basic syntax of pointers
- how pointers differ from normal variables
- how to inspect pointer behavior with simple examples
