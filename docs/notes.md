# Go Study Notes

## Basics

- Go is a simple and efficient programming language.
- Use `go run` to run a file quickly.
- Use `go build` to compile a program.

## Important concepts

- Variables and constants
- Functions and packages
- Loops and conditionals
- Arrays, slices, and maps
- Pointers and memory references

## Good study habits

- Practice daily, even for 20-30 minutes.
- Write your own examples instead of only reading them.
- Keep notes after every lesson.
