# Go study guide

This document provides a simple roadmap for learning Go using this repository.

## Suggested order

1. Start with Chapter 1 to learn the basic structure of a Go program.
2. Continue to Chapter 2 to understand modules and workspace concepts.
3. Practice input, output, formatting, and calculations in Chapters 3 to 5.
4. Study dates, time, and pointers in Chapters 6 and 7.
5. Use the practice folder to reinforce your knowledge.

## Recommended practice routine

- Read the chapter file and notes.
- Run each example with `go run`.
- Modify the program slightly to test your understanding.
- Write your own mini example for each concept.

## Common Go commands

```bash
go run <file>.go
go build <file>.go
go install ./...
go mod init example.com/myapp
```
