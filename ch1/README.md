# Chapter 1: First Go program

This chapter introduces the basic structure of a Go program.

## Key ideas

- Every Go program uses the `main` package.
- The `main` function is the entry point.
- The `fmt` package is used for printing output.
- The `strings` package can help transform text.

## Example file

- `hello.go` : prints a greeting and converts text to uppercase.

## What to learn

- how to write a simple Go program
- how to import packages
- how to use `fmt.Println` and `fmt.Printf`
