# Chapter 5: Arithmetic and calculations

This chapter explores basic arithmetic operations and numeric handling in Go.

## Key ideas

- use arithmetic operators for addition, subtraction, multiplication, and division
- work with integers and floats
- use `math/big` for large-precision numbers

## Example file

- `arithmatic.go` : demonstrates arithmetic and big-number calculations

## What to learn

- how to perform calculations in Go
- how to work with different numeric types
- how to use `big.Float` for more precise values
